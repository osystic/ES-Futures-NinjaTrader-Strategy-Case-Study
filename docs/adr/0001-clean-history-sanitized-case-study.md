# ADR-0001: Clean-history sanitized case study

- Status: Accepted
- Decision date: 2026-08-30
- Related issue: #2
- Approval: OSYSTIC Founder & CEO

## Context

The completed client engagement contains confidential NinjaScript, raw NT8 evidence, private data and commercial context. Prospective clients need verifiable capability proof without receiving another client's protected source.

## Decision

Maintain this repository as an independent, public, sanitized case study. Publish only approved architecture, methodology, aggregate results, limitations and lessons.

## Consequences

- no fork, mirror or copied private Git history;
- no strategy source, raw evidence, private data or client identity;
- claims remain tied to the approved private evidence record;
- final status remains research/paper-trading only and live/funded NO-GO;
- publication can be corrected or withdrawn if evidence or approval changes.
