# Governance Exceptions and Platform Limits

## GitHub account model

This repository is owned by the `osystic` GitHub User account rather than an OSYSTIC GitHub Organization. Organization base permissions, team routing, organization 2FA enforcement and organization-level rulesets cannot be claimed here.

Compensating controls:

- `@osystic` CODEOWNERS routing;
- issue-first changes and short-lived branches;
- PR validation and squash-merge policy;
- public disclosure CI;
- founder approval for claims, visibility and withdrawal;
- no confidential implementation in the public repository.

Review this exception before migration to an organization account or when stronger GitHub Team enforcement becomes necessary.

## Enforcement limitation

CODEOWNERS and policy can route/review changes, but settings not available or configured on the current account/plan are operating controls rather than falsely claimed technical prevention. Any bypass must be recorded with owner, reason and review date.
